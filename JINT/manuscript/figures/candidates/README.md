## Formal Trial Bar-Chart Helper (For Post-Fieldwork Results)

When `~/data/jint/field_log.csv` is populated after the 4-condition trials, run from `JINT/analysis/`:

```bash
python3 render_candidate_figures.py --field-log ~/data/jint/field_log.csv
```

This adds `cand_formal_outcomes_wilson.pdf` using the exact condition/layout classification and 95% Wilson interval logic from `summarize_trials.py`.
