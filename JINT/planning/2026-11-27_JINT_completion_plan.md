# JINT 투고를 위한 실험·원고 마감 계획

2026-11-27 KST · 공저자 검토용 · [현재 원고](../JINT_first_draft.pdf)

**권장안은 팔각정 낮의 동일 경로 비교 5쌍과 5열람실의 V-LiDAR 확인 주행 5회다.** 새 주행은 계획상 15회이며, 공통 프로토콜로 판정할 수 있는 자료가 있으면 해당 회차를 먼저 검토한다. 구름다리는 기존 카트·통 회피와 실패 분석을 쓴다. 팔각정 밤은 조명 차이를 주요 연구 질문으로 삼을 때 추가한다. 네 조건의 반복 수를 맞추는 작업보다 **동일 조건 비교와 독립 현장 판정**을 우선한다.

## 투고 판단의 근거

- JINT는 지능형 로봇 시스템의 설계와 시험을 포함하는 독창적 연구를 다룬다. 관련 연구에서는 실제 실내 로봇과 정량 지표를 연결하거나, 기록된 영상에서 RGB-D 기반 방법과 같은 과제를 비교했다. 이 사례에서 가져올 점은 주장을 직접 검증하는 평가를 설계하고 비교 조건을 밝히는 것이다. 아래 횟수는 우리 팀의 작업량과 증거 수준을 고려한 계획값이다. [JINT 연구 범위](https://link.springer.com/journal/10846/aims-and-scope) · [Lan 등, 실내 로봇 검증](https://link.springer.com/article/10.1007/s10846-026-02364-2) · [Lopes 등, 단안 깊이와 RGB-D 비교](https://link.springer.com/article/10.1007/s10846-024-02131-1)
- IJCAS AE는 단일 복도·박스와 비교 기준 부족을 지적했고, IEEE Access에서는 물리 2D LiDAR 또는 시각 대안과의 비교, 실제 결과 측정과 재현성을 물었다. 우리 원고는 **단안 RGB의 가상 스캔을 표준 Nav2에 연결했을 때 정적 장애물과 10 m 목표에서 어떤 동작과 한계가 관측되는가**를 다룬다. 관측 가능한 근거리 범위, 실제 회피 결과, 센서와 제어의 시간축을 연결해 답한다. [IJCAS 의견](../../paper/review/09_IJCAS_Review_Priority_and_3D_LiDAR_Option_20261118.md) · [IEEE Access 리뷰](../../paper/review/01_IEEE_Access_Decision_and_Raw_Reviews.md)

## 현장 한 세션으로 확보할 근거

| 우선순위 | 장소·실험 | 새 주행 목표 | 확인할 질문 |
| --- | --- | ---: | --- |
| 1 | **팔각정 낮. 같은 로봇·박스·10 m 경로에서 V-LiDAR와 비교 방법을 한 쌍씩 교대** | 5쌍 = 10회 | 동일 조건에서 각각 성공·접촉·개입·복구가 어떻게 달라지는가 |
| 2 | **5열람실. 동일 박스 배치에서 V-LiDAR** | 5회 | 좁고 인공조명 위주의 새 환경에서도 실제 판정이 확인되는가 |
| 3 | **팔각정 밤 또는 구름다리 보강** | 필요할 때만 확정 | 팔각정 밤은 낮·밤 직접 비교가 논문의 주요 질문일 때 같은 구간에서 수행한다. 구름다리는 대표 자료 또는 실제 판정이 부족해 결론에 영향을 줄 때 보강한다. |

**비교 방법은 촬영 전에 하나를 정한다.**

1. **물리 2D LiDAR를 당일 설치하고 확인할 수 있을 때** 같은 로봇과 Nav2, 목표·장애물·중단 규칙을 유지하고 실제 스캔과 가상 스캔을 교대로 입력한다. 센서 장착 위치, TF, 시야각 차이를 기록한다. 물리 센서의 전체 시야를 썼다면 결과를 두 배포 구성의 비교로 해석한다.
2. **물리 LiDAR 없이 진행할 때** 기존에 실행이 확인된 **MiDaS v2.1 Small을 1순위 후보**로 삼는다. 현재 확인된 것은 오프라인 CPU 지연(평균 37.32 ms)이다. 실차 비교에 쓰려면 별도 보정 장면에서 거리 스케일을 맞추고, 독립 검증 장면에서 앞의 박스가 같은 좌표 원점의 스캔으로 들어오는지와 실제 갱신률을 확인한다. 비교 때 카메라 시야, 공통 거리 구간, 스캔 프레임과 Nav2 설정을 맞추고 각 방법의 실제 갱신률을 함께 보고한다. [기존 CPU 벤치마크](../analysis/evidence/pytorch_comparison_summary.csv)
3. **외부 비교가 출발 점검을 통과하지 못하면** 팔각정 5쌍을 V-LiDAR의 시간 필터 켜기·끄기로 실행한다. 현재 우회 비교는 오프라인 재생에서 수행했다. 실차에서는 필터만 우회할 수 있는 실행 설정을 준비하고, 나머지 출력 형식·Nav2 설정이 같은지 확인한다. 카메라 대안과의 오프라인 비교를 추가할 수 있다면 별도로 확인한 장애물 구간과 거리 기준을 쓰고 보정에 쓴 장면은 평가에서 뺀다. 외부 방법의 폐루프 결과가 없으면 비교 부족에 대한 심사 리스크를 교신저자와 판단한다.

**수행·집계 기준**

- 출발점과 10 m 목표 중심, 동일 박스의 좌표와 차체 통과 공간을 줄자로 표시한다. 목표 중심 반경 0.50 m에 차체의 표시 기준점이 들어오고 접촉·수동 개입 없이 시도가 종료되면 성공이다. 현장 관찰자 또는 고정 영상으로 확인한다. 배치·설정 ID와 성공·접촉·개입·중단 사유를 회차마다 남긴다. 목표 수락부터 반경 첫 진입까지 같은 방식으로 잰 회차만 도달 시간에 사용한다.
- 비교 순서는 두 방법의 첫 순서가 섞이게 촬영 전에 정한다. 각 시도 사이에 시작 자세와 장애물을 같은 표시로 되돌리고, CSV에 방법·쌍 ID를 연결한다. 종료 규칙을 공통으로 적는다. 기존 90초 이후 복구 사례를 고려해 장기 정체를 어떻게 종료할지 미리 정한다. 정한 시도 수 안에서 성공·실패를 모두 남긴다. 외부 통행이나 저장 실패로 해당 시도를 판정할 수 없다면 사유와 대체 회차 ID를 함께 남긴다.
- 새 주행 전 짧은 진단 두 회차에서 **정지·이전 목표 종료·리셋·새 odom**을 확인한다. 바퀴가 정지했는데 odom이 다시 흐르거나 이전 목표 종료가 확인되지 않으면 그 구간을 먼저 진단한다. 설정 스냅샷과 첫 bag의 실제 디코딩을 확인한 뒤 같은 설정으로 반복한다. [리셋 점검](2026-11-27_odom_reset_plan.md)
- 결과표는 방법·장소별 성공/판정 가능, 시도 총수, 접촉·개입·무효·미판정을 적는다. 각 비율의 95% Wilson 구간과 팔각정에서 두 방법이 서로 다른 결과를 낸 쌍 수를 제시한다. 다섯 번 모두 성공해도 95% Wilson 구간은 약 57–100%다. 작은 표본으로 동등성, 우월성 또는 환경 전반의 성공률을 결론 내리기 어렵다. 더 정밀한 추정이 주요 주장이라면 촬영 전에 반복 수를 다시 산정한다.

## 원고 마감과 제출 판단

1. **현장 전에 할 일.** 기존 회차 근거 수집, 5열람실 정체·의자 반환 추가 분석, 비교 후보의 스캔 출력 점검을 병행한다. 로봇 담당은 odom·취소·설정 스냅샷, 현장 담당은 표시와 독립 판정, 원고 담당은 회차 ID 연결과 표·그림 생성을 맡는다.
2. **현장 뒤 할 일.** 방법·결과와 집계 코드의 조건을 실제로 수행한 장소·비교군에 맞춘다. Figure 4는 실제 사용한 환경 사진으로 구성하고, 대표 회피와 정체·복구 그림을 본문에 둔다. 원고에서는 독립 판정 결과를 먼저 제시하고, 기존 홀 자료와 구름다리·5열람실 파일럿을 별도로 보고한다. 대조된 값이 비슷하거나 필터가 반응을 늦춘 경우도 적는다. 초록·결론에서 수치의 분모와 주장 범위를 표와 일치시킨다. [집계 도구](../analysis/summarize_trials.py)
3. **제출 전 확인.** 현장 성공의 독립 근거와 짝지은 비교가 확보되고 대표 제한·실패를 로그로 설명할 수 있으면 투고를 권장한다. 외부 방법의 비교가 빠지면 시간 필터 실차 비교로 얻은 기여와 남는 검증 공백을 교신저자와 확인한다. 장비·모델·LUT 버전, 확인 가능한 학습 데이터 출처와 분할, 현장 CSV 및 공개 가능한 기록의 접근 경로를 정리한다. 공저자 승인·연구비·이해충돌, ICCAS 선행 공개 범위와 IJCAS 상태를 확인하고 최종 PDF·LaTeX ZIP·보충자료·커버레터를 검증한다. JINT의 Data Availability Statement에 결과 근거의 접근 방법을 기재한다.
