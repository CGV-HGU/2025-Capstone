# 피규어·표 구성 및 원자료 확보 계획

상태: **제작 계획**. F01~F09와 T01~T04는 작업 ID이며 최종 논문 번호가 아니다. 제안 파일명은 산출 예정 이름이며 현재 존재하는 결과를 뜻하지 않는다. 아래 계획으로 실제 그림이나 원고를 교체하지 않았다.

## 1. 원칙과 현황

그림은 리뷰의 질문과 입력 데이터에 연결한다. 새 주행을 하지 않는 기존 자료 정리(D), 새로운 오프라인 실행(O), 현장 취득(E)을 구분한다. 실제 경로·마스크·성공률은 원자료에서만 만들고, 개념도에는 실제 측정 결과가 아니라는 점을 명시한다.

현재 원고 [main.tex](../../workspace/IEEE_Access/main.tex)의 이미지 7개는 로컬에서 실제 이미지로 읽을 수 있음을 확인했다. 기존 Fig. 2 기하 도식은 TeX 내부 `picture`다. 이미지 크기가 크거나 과거 체크리스트에 완료 표시가 있어도 내용과 수치가 검증됐다는 뜻은 아니다.

## 5. 촬영·제작 규격과 출처

- **현장 촬영 순서:** 물체 없는 공간 전경 → 축/치수가 보이는 S1~S3 배치 → 장착 측면 → 전체 외부 주행 영상. 촬영 장치의 위치·시각/동기 방식과 파일 ID를 남긴다. 측정 전경은 미관을 위해 물체 위치를 바꾸지 않는다.
- **대표 주행 선택:** 각 조건 성공 주행 중 경과 시간이 중앙값에 가장 가까운 회차를 기본으로 하고, 실패는 유형별 대표를 추가한다. 같은 선정 규칙을 모든 조건에 적용하고 제외 이유를 남긴다. 선택된 예시와 전체 결과 그림을 함께 제공한다.
- **기존 원본 후보:** Trash `nav_debug_avoidance`는 의자, `.3`은 카트/스탠드, `.4`는 자연광·반사, `.5`는 좁은 통로·장시간 정지. SSH로 bag별 2/8/20/50/85% 시간의 대표 이미지 5장씩을 확인했지만, 전체 주행의 자율성·성공을 입증한 것은 아니다.
- **축과 집계:** m/s/ms 단위, trial/clip/frame 표본 수, 실제 오차막대 정의를 캡션에 포함. 프레임 수를 독립 반복 수로 표시하지 않음. 이동 중 scan 변화는 정적 jitter와 구분.
- **출력 제안:** 도식·통계 그림은 SVG 또는 벡터 PDF와 원본 CSV/제작 스크립트. 사진은 원본 유지, 합성 패널은 읽을 수 있는 해상도(최종 크기 기준 약 300 dpi를 출발점)로 출력. 최종 저널 규격은 타깃 확정 후 확인.
- **가독성:** 최종 인쇄 크기에서 글자/범례/치수 확인. 같은 조건은 같은 색·선형을 쓰고 색에만 의존하지 않음. crop/보정이 해석을 바꾸지 않게 원본·처리 내역 보존.
- **출처:** [asset_manifest.csv](templates/asset_manifest.csv)에 figure/panel ID → bag/영상·trial/clip → timestamp/채널 → 처리 코드·파라미터 → 출력 파일을 연결한다. 인물이 보이는 프레임을 공개할 때에는 사용 범위와 필요한 비식별 처리를 확인한다.

캡션 틀: “(조건/장소)에서 (실제 수행한 측정)을 나타낸다. 패널 (a)~(c)는 (trial/clip ID, 시각)에 해당한다. 궤적은 (측정 방법), 오차막대는 (정의), n은 (독립 단위)다. (확인된 한계).”

예정 산출명: `fig_environment_protocol`, `fig_navigation_sequence`, `fig_all_trial_trajectories`, `fig_outcomes_by_condition`, `fig_failure_cases`, `fig_static_baseline`, `fig_training_curves`. 해당 파일은 아직 생성하지 않았다.
