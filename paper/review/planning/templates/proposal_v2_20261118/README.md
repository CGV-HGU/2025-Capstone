# v2 현장 계획표: 미실행 제안

[현행 실험·코드 계획](../../04_Robot_Checked_Code_and_Experiment_Plan_20261118.md)의 부속 표다. 기존 상위 폴더의 `proposal_v1` 계획과 합산하지 않는다. 모든 행은 `planned`이며 실제 결과가 아니다.

- `trial_plan.csv`: 3장소×2배치×10반복=60회, 제안 방식 하나의 폐루프 주행. 각 장소에서 block당 두 배치를 한 번씩 수행하도록 순서를 섞었다. 시작/물체/목표 좌표는 예비 실험에서 통과 여유를 확인하고 본 평가 전에 고정할 잠정값이다.
- `static_clip_plan.csv`: D1 거리3×방위3×독립 재배치3=27클립(보정9/평가18), D2 새 배치3×광학 조건3=9클립(전부 평가). D1은 통제 가능한 한 장소, D2는 광택 조건이 있는 한 장소에서 수행할 제안이다. baseline의 다장소 일반화를 증명하는 설계는 아니다.
- 고정 seed `20261118`로 계획 순서만 섞었다. 실제 취득 순서는 별도로 남긴다. D2는 한 재배치 내 세 광학 조건을 짝지어 분석한다. 연속 프레임을 독립 반복으로 세지 않는다.
- `planned_range_m`는 사전 정의할 scan 원점에서 물체 전면 기준점까지의 평면 방사 거리다. 실제 GT·물체 크기·기준점·측정 불확실성은 별도로 실측한다.

실제 기록에는 상위 폴더의 [field_log.csv](../field_log.csv), [static_measurement_log.csv](../static_measurement_log.csv), [asset_manifest.csv](../asset_manifest.csv)를 사용하고 `protocol_id=proposal_v2_20261118`로 연결한다. `plan_id/clip_plan_id`는 이 폴더 표의 ID와 일치시킨다. 계획값을 실측값이나 성공 결과로 복사하지 않는다.

조건·반복 수·고정 좌표가 바뀌면 본 평가 시작 전에 계획 문서와 CSV를 함께 갱신한다. 이미 취득한 결과를 덮어쓰지 않는다. v2도 일정·장소·인원 확인 전의 초안이다.
