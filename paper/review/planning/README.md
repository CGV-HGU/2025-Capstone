**팀원은 [팀원용 안내](00_Team_Briefing.md)를 먼저 읽으면 된다.** 무엇을 준비하고, 왜 60회를 수행하며, 사진·영상은 무엇을 남겨야 하는지 정리했다. 전문 용어와 상세 조건은 아래 문서로 연결한다.

## 1. 이번 목표와 범위

교수님과의 대화에서 합의된 순서는 제어로봇시스템학회지 작업 마무리 후 **이전 리뷰에서 남은 검증을 우선 보완**하는 것이다. Access 신규 요구 전체를 이번 일정에 포함하지 않는다.

대화에서는 IJCAS라고 했지만, 현재 저장소에서 확인한 이전 원문은 [ICCAS 리뷰](../../../docs/reviews/comment.txt)로 보관돼 있다. 별도 IJCAS 심사 원문을 확인하기 전까지 아래 U1~U4는 이 원문에 대응한다. 심사 원문과 팀의 과거 제안, 이번 계획을 구분한다.

| ID | 이전 리뷰의 지적 | 이번 대응 | 완료 기준 |
| --- | --- | --- | --- |
| U1 | 단일 복도·정지 박스 1개 | 다른 실제 장소 2곳, 장애물 조건 3종의 반복 폐루프 주행 | 조건별 전체 시도·성공/실패 및 환경 사진·궤적 확보 |
| U2 | 실패율 22% | 고정한 현재 시스템의 성공률과 실패 유형 평가 | 충돌·정지·개입을 포함해 분모와 불확실성 보고 |
| U3 | 광택 바닥·조명 민감도 | 반사/조명 차이가 있는 환경과 기존 실패 영상 분석 | 어떤 조건에서 무엇이 실패하는지 근거와 한계 제시 |
| U4 | LiDAR **또는 대체 baseline** 비교 부재 | 기존 MiDaS/Depth Anything V2 수치 검증, 필요 시 동일 입력·독립 정답으로 재평가 | 보정/평가 분리 및 수치 출처 재현 |

90회, 좁은 복도 필수, 물리 LiDAR 필수는 위 원문에 지정돼 있지 않다. [과거 90회 계획](../../archive/submitted_papers/experimental_data/Obstacle_Avoidance_Experiment_Plan.md)은 팀이 제안한 설계다. 이번 **60회**도 제안이며, 통계적 충분성·원인 규명·리뷰 수용을 보장하지 않는다.

## 3. 우선순위와 일정 판단

1. **준비:** 원본 보존 확인, 이전 원문 대조, 모델 클래스 처리·실제 실행 설정·좌표계·녹화 확인.
2. **필수 현장 작업 E1:** `2환경 × 3조건 × 10회 = 60회`가 기본안. 예비 주행은 이 분모에서 제외한다.
3. **권장 측정 E2:** 기존 baseline/거리 수치의 근거를 회복하지 못하면 18개 정적 클립으로 새 비교 입력 확보. 이 경우 현장 일정에 포함한다.
4. **병행 문서 작업 D:** 기존 학습 곡선·궤적 정리, 운용 범위·주장 수정안, 피규어 틀·캡션·출처 표 준비.
5. **조건부 오프라인 작업 O:** baseline 재추론, 필터 비교, 수동 정답을 이용한 인식 평가. 로봇 주행이 없어도 새로운 실험이다.

실험 1일차 준비·예비 주행·E2, 2일차 환경 A 30회, 3일차 환경 B 30회와 누락 점검을 목표로 한다. **첫날 설정을 고정하지 못하면 3일 완료 예상은 재산정**한다. 현장 2명(운영/관찰·기록)을 가정하며 담당자는 미정이다. 분석·오프라인 실행·원고 반영은 별도 작업이다.

실제 LiDAR 동시 비교, 새 경량 MDE 모델 도입, 카메라 장착 변경, 동적 보행자, 임베디드 보드 실측은 이번 필수 범위에서 보류한다. 이를 하지 않은 상태에서 범용 LiDAR 대체·동적 장애물 대응·저사양 실증을 주장하지 않는다.

## 4. 현재 완료된 것과 남은 것

- **확인 완료:** 기존 리뷰 원문 대조, 로봇 PC 접속, bag 폴더 40개 존재, 20회 보고 bag의 영상 토픽 부재, 영상 bag 6개의 메시지 수, 4개 bag의 대표 프레임 20장, 원격 소스/설정과 로컬의 일치.
- **계획 작성 완료:** 추가 실험·그림·비실험 작업 목록 및 빈 기록 양식.
- **미완료:** 물리 장소 확정, 배터리/모터/전체 노드 점검, 모델 재추론, 원인 확정, 60회/18클립 취득, 실제 피규어 제작·원고 수정.
- **핵심 근거 공백:** 원고의 `0.192 m` 동적 MAE와 기존 보고서 `1.529 m`의 연결, OpenVINO 온라인 실행 주장, 20개 영상 없는 bag을 입력으로 기술한 이미지 기반 ablation의 별도 자료, 데이터셋 출처·분할.

기존 02~05 보고서와 종합 보고서는 심사·자산 분석의 배경 자료다. 이번 실행 우선순위와 실제 측정 여부는 이 계획 및 06의 제한 사항을 함께 적용한다. 성공률 목표를 달성 결과로, ROI 신호를 인식 정확도로, 정지한 로봇의 scan 재생을 새 폐루프 성공률로 대체하지 않는다.
