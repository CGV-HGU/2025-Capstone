# 팀원용 안내: 이번에 무엇을 준비하고 끝낼 것인가

**현재 상태는 계획 수립까지다. 새 실험 60회, 정적 측정, 결과 피규어는 아직 수행·제작하지 않았다.** 교수님과 합의된 우선순위는 제어로봇시스템학회지를 마친 뒤 이전 리뷰의 미흡한 검증을 보완하는 것이다. 아래 실험 횟수·세부 배치는 팀 실행을 위한 제안이다.

## 1. 왜 다시 실험하는가

이전 리뷰의 핵심은 “한 장소에서 박스 하나를 피한 결과만으로 충분한가”, “실패가 왜 생기는가”, “반사광/조명 변화에 견디는가”, “다른 방법과 비교했는가”다. 팀 대화에서는 IJCAS라고 했지만 저장소 원문은 ICCAS로 보관돼 있다. 명칭을 확정하기 전에도 이 네 항목을 기준으로 준비할 수 있다.

**이번에는 서로 다른 장소 2곳에서, 세 가지 장애물 배치를 각각 10번 주행하는 것을 기본으로 제안한다.** 실제 LiDAR를 새로 달거나 움직이는 사람을 피하는 실험은 이번 기본안에 넣지 않았다.

## 2. 현장에서 할 일

| 무엇 | 어떻게 | 왜 필요한가 |
| --- | --- | --- |
| 장소 2곳 | A: 기준 홀, B: 다른 장소의 반사/조명 변화 구간. 충분한 우회 공간 확보 | 단일 환경 한계 보완 |
| 장애물 3조건 | 박스 1개, 의자/카트 1개, 박스 2개 연속 배치 | 단일 박스 한계 보완 |
| 본 주행 60회 | 장소별 3조건 × 10회. 연습/튜닝은 따로 기록 | 조건별 성공·실패를 반복 평가 |
| 정적 측정 18클립 | 필요 시 장소별 2.5/3.5/4.5 m에서 물체를 3번씩 다시 배치·측정 | 기존 비교표의 거리 정답이 복구되지 않을 때 사용할 자료 |
| 사진·영상 | 장소 전체, 바닥 치수/물체 배치, 카메라 장착, 외부 주행 영상 | 논문 그림과 실험 조건 설명 |

세팅 좌표와 매 회차 절차는 [상세 실험 계획](01_Experiment_Setup_and_Three_Day_Plan.md), 순서는 [60회 계획표](templates/trial_plan.csv)에 있다. 자리/물체/설정이 확정되기 전에는 계획 숫자를 실제 측정값으로 취급하지 않는다.

## 3. 역할별 준비물과 당일 담당

담당자는 아직 배정하지 않았다. 현장에서는 운영과 관찰·기록을 최소 2명이 나눠 맡는 것을 가정한다.

| 역할 | 실험 전에 준비 | 실험 중/후 할 일 |
| --- | --- | --- |
| 로봇 운영 담당 | 충전, 장비·모터·정지 수단 확인, 카메라/실행 설정 확인 | 시작점 정렬, 녹화/목표 전송, 종료와 설정 변경 기록 |
| 관찰·기록 담당 | 장소 확보, 박스 2개·의자/카트·줄자·표식·외부 카메라 | 물체 배치·거리 확인, 접촉/개입 관찰, 판정·영상·시도 ID 기록 |
| 자료 분석 담당 | 기존 수치 출처 확인, 기록 양식·파일 ID 준비, 저장 용량 확인 | bag 점검·백업 확인, 전체 결과 집계, 그림·표·비교 실험 정리 |

한 사람이 분석 역할을 겸할 수 있다. 로봇을 조작하면서 모든 접촉·파일·시간을 혼자 기록하는 일정은 가정하지 않는다.

## 4. 3일 동안 무엇을 끝내는가

| 날짜 | 할 일 | 끝났다고 판단하는 기준 |
| --- | --- | --- |
| 1일차 | 장비/두 장소 세팅, 예비 주행, 녹화 확인, 정적 측정, 사진 촬영 | 같은 설정으로 반복할 수 있고 필요한 데이터가 실제 저장됨 |
| 2일차 | 환경 A 30회 | 실패도 포함한 시도 기록과 원본이 연결됨 |
| 3일차 | 환경 B 30회, 누락·백업 확인 | 양 환경의 분석 가능한 데이터 확보 |

**첫날까지 설정을 고정하지 못하면 일정은 늘려 잡아야 한다.** 3일은 현장 취득 목표다. 기존 baseline 재평가, 그래프/통계, 원고 반영까지 3일에 모두 끝낸다는 뜻은 아니다. 새 환경에서 실패한 결과도 결과이며, 성공률을 맞추려고 실패 기록을 버리지 않는다.

## 5. 실험이 끝나면 어떤 그림이 나오는가

| 핵심 그림 | 현장에서 꼭 남길 것 |
| --- | --- |
| 두 장소와 장애물 배치도 | 장소 전경, 폭/거리/물체 크기, 출발·목표·배치 표식 |
| 접근 → 회피 → 복귀 과정 | 같은 주행의 외부 영상과 카메라/스캔/계획 시각 정보 |
| 전체 주행 궤적 | 모든 본 평가의 odom, 시작 방향, 장애물 위치, 성공/실패 ID |
| 조건별 성공률·실패 유형 | 전체 시도와 접촉·정지·개입 판정. 잘된 회차만 모으지 않음 |
| 반사광·실패 사례 | 문제 전후 영상·속도·스캔·가능한 costmap/진단 |
| 다른 방법과 거리·처리 시간 비교 | 같은 영상, 독립적으로 측정한 거리, 보정과 평가 자료의 구분 |

실제 그림을 만들 때 필요한 패널과 출처는 [피규어·표 계획](02_Figure_and_Table_Plan.md)에 있다. 정지한 박스를 피하는 주행을 “움직이는 장애물 회피”라고 설명하지 않는다.

## 6. 로봇을 움직이지 않고 지금 할 수 있는 일

- **새 실험 없이 가능:** 기존 리뷰 대응표, 학습 곡선, 기존 궤적·정지 사례 정리, 논문 주장/한계 정리, 그림 구성·캡션·양식 준비.
- **새 주행 없이 가능하지만 오프라인 실험은 필요:** 기존 영상에 모델을 다시 돌리는 비교, 필터 전후 비교, confidence/왜곡 보정 민감도 평가. 원본 영상과 경우에 따라 수동 정답이 필요하다.
- **새 현장 취득 필요:** 조건을 맞춘 반복 주행, 독립 거리 정답, 현재 환경·장착·배치 사진과 치수.

현재 우선 확인할 문제는 비교표 `0.192 m`와 기존 보고서 `1.529 m`의 출처 차이, 바닥/사람 마스크 처리, 실제 실행 설정, 영상 없는 20개 bag과 이미지 기반 ablation 입력의 관계다. “바닥 감지 신호가 계속 True였다”만으로 인식이 정확했다거나 Nav2가 원인이라고 확정하지 않는다.

상세 분류와 기존 자료 위치는 [기존 자료 활용 계획](03_Existing_Data_and_Desk_Work_Plan.md)을 본다.

## 7. 현장에 가기 전 체크

- [ ] 장소 A/B와 시간, 역할별 담당자를 정했다.
- [ ] 박스 2개·다른 형상 물체·측정 도구·충전·외부 촬영·저장소를 준비했다.
- [ ] 실제 장착/설정과 바닥 클래스 처리, 로봇 작동을 확인했다.
- [ ] pilot 영상과 주행 기록이 실제 디코딩·분석되는지 확인했다.
- [ ] 판정·제한 시간·설정·장애물 좌표를 고정하고 pilot과 본 평가를 분리했다.
- [ ] [현장 기록](templates/field_log.csv), [정적 측정 기록](templates/static_measurement_log.csv), [그림 출처 기록](templates/asset_manifest.csv)을 준비했다.

위 체크는 현재 모두 미완료 상태의 준비 목록이다. 기존 원본은 휴지통에도 있으므로 필요한 자료의 복사·무결성 확인을 먼저 계획한다. 이번 문서 작성 과정에서 원격 원본을 이동하거나 지우지 않았다.
