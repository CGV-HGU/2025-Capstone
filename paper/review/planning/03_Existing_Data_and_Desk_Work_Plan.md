# 기존 자료 활용과 추가 실험 없는 작업의 범위

상태: 실행 분류와 작업 계획. **새 주행 없음**과 **추가 실험 없음**은 다르다. 기존 bag으로 모델을 다시 실행하거나 새 정답을 만들어 성능을 평가하면 오프라인 추가 실험이다.

## 1. D: 새 실험 실행 없이 가능한 작업

| ID / 우선순위 | 작업·입력 | 결과물 | 한계와 완료 기준 |
| --- | --- | --- | --- |
| D1 / P0 | [이전 원문](../../../docs/reviews/comment.txt)·교수님 합의·기존 대응 대조 | U1~U4 대응표와 이번 범위 | IJCAS 별도 원문 미확인 표시. Access 신규 요구를 원래 요구에 섞지 않음 |
| D2 / P0 | 기존 인벤토리와 원본 경로·상태 정리 | bag/영상/설정별 자산 목록, 백업 필요 목록 | 40개 폴더는 독립 40회 아님. 압축/비압축 복사본 중복, 카메라 없는 bag 구분. 휴지통 원본 복사·검증은 데이터 관리이며 이번에 수행하지 않음 |
| D3 / P0 | 원고 표와 기존 로그·스크립트 출처 추적 | 수치별 입력·방법·백엔드·실행 로그 연결표 | 출처 없으면 검증 대기. 모양이 비슷한 숫자로 대체하지 않음 |
| D4 / P1 | 기존 `trajectories/*.csv`, 20회 metrics 시각 정리 | 과거 주행 궤적·정지 구간·ROI 상태 그림 | odom/scan 기반 기술 통계. 과거 미보고 로그를 새로운 반복 성공률로 승격하지 않음 |
| D5 / P1 | `yolo11n_seg_train_results.csv`, checkpoint meta | 100 epoch 학습 곡선, 학습 설정/validation 지표 표 | 기록된 2클래스 집계 성능. floor-only test mIoU가 아님. 이미지 수·분할·출처는 별도 확인 |
| D6 / P1 | 현재 수식·코드 및 운용 조건 검토 | 기하 도식, 지연 정의, 주장/한계/TCO 수정안 | 이론과 측정을 구분. 지연을 N=2만으로 무조건 200 ms라고 단정하지 않고 샘플 위상·스케줄·EMA/초기화 정의를 명시 |
| D7 / P1 | 확인한 원본 프레임과 시계열 | 의자·카트·역광·좁은 통로의 관측 사례, 캡션 초안 | 사례 존재를 확인한 것. 독립 GT 없는 범위에서 정성 분석에 제한 |
| D8 / P1 | 피규어 panel/캡션·현장 기록지·실험 순서 준비 | [피규어 계획](02_Figure_and_Table_Plan.md), 빈 양식 | 계획에 완료값/가상 결과를 넣지 않음 |

D4/D5의 기존 결과 재집계·그림 제작은 새 모델/로봇 실험 없이 가능하지만, 이번 커밋에서 실제 결과 그림을 새로 생성한 것은 아니다. 원자료에서 새 평가 지표를 도출할 때에는 그 방법과 검증 수준을 별도로 기록한다.

## 2. O: 새 주행 없이 가능한 오프라인 추가 실험

| ID | 작업 | 필요한 것 | 주장할 수 있는 범위 |
| --- | --- | --- | --- |
| O1 / P0 | MiDaS/DA-V2/V-LiDAR 재평가 | 영상·독립 GT·보정/평가 분리, 표적 대응·yaw·외인자 처리, 백엔드 기록 | 센서 출력 정확도·무검출·처리 시간. 실제 baseline 주행이 없으면 폐루프 성능 비교 불가 |
| O2 / P1 | floor class 처리·confidence 변화 검증 | 실제 가중치·클래스·원본 프레임, 필요한 수동 정답과 분리된 평가 구간 | 해당 프레임/조건에서의 mask·scan 변화. ROI True 비율을 정확도라고 부르지 않음 |
| O3 / P1 | 필터 전후·모듈 ablation | 같은 입력의 순차 재생, 동일 모델·기하, 상태 초기화/warmup, 정답 또는 안정성 지표 | 인식·scan 단계의 변화. 고정된 과거 영상으로 새로운 폐루프 완주율을 측정한 것으로 해석 불가 |
| O4 / P2 | 왜곡 보정·confidence/가림·조명 민감도 | 캘리브레이션과 보정에 맞춘 LUT/좌표계, 분리된 평가 자료 | 제한된 오프라인 민감도. undistort만 넣고 기존 LUT를 그대로 쓰는 비교는 기하 불일치 여부 확인 |
| O5 / P2 | 실제 백엔드 추론 지연·자원 제한 측정 | 하드웨어·스레드·부하·정밀도·측정 구간 고정 | 해당 PC 조건에서의 처리 시간. CPU 코어 제한은 다른 임베디드 보드의 실측 대체가 아님 |

영상 재추론 입력은 로봇 PC에 있다. 추출 CSV만으로 새 mask나 MDE depth map을 만들 수 없다. O1에서 기존 GT를 복구하지 못하면 [E2 정적 취득](01_Experiment_Setup_and_Three_Day_Plan.md)이 필요하다. O2/O3에서 수정이 필요하면 코드 변경과 재검증을 별도 작업으로 관리한다.

## 3. E: 현장 취득이 필요한 것

- **E1 다환경·다장애물 폐루프 반복:** 기존 bag은 장면 다양성을 보강하지만, 프로토콜·시작/목표·개입·실행 설정이 확인되지 않은 bag들을 합쳐 반복 성공률로 쓰지 않는다.
- **E2 독립 GT 측정:** V-LiDAR `/scan`은 제안 기법의 출력이며 다른 방법을 평가하는 독립 정답이 아니다. 거리계/줄자와 외인자 확인으로 정답을 확보한다.
- **E3 수정 효과의 폐루프 검증:** 과거 고정 경로의 scan을 planner에 재생한 결과만으로 실제 로봇의 수정 후 완주율을 대신하지 않는다. 필요한 경우 별도 전후 반복을 설계한다.
- **조건부 현장 기록:** 환경·장착·배치 치수/사진은 새 주행 없이 취득할 수 있지만 현장 작업은 필요하다. F03 제작을 위해 일정에 포함한다.

실제 LiDAR, 움직이는 보행자, 장착 높이/틸트 변경, 새 보드 검증은 Access 전체 대응의 후속 후보이며 이번 기본안에서 제외한다. 추후 목표 저널·주장에 따라 다시 판단한다.

## 6. 권장 진행 순서와 종료 산출물

**바로 진행 가능한 문서 작업:** D1/D2/D3/D8 → D4/D5/D6/D7. 계획·빈 양식은 이번 커밋에 포함하고, 통계 그림·원고 문장 반영·실제 실행은 별도 수행 상태로 관리한다.

**현장 전:** G1~G5, 원자료 백업/복사본 무결성 확인, baseline 근거 복구 가능성 판단. **현장:** E1, 필요 시 E2, 피규어 촬영. **취득 후:** O1 및 필요한 O2/O3, 전체 결과 그림/표, 리뷰 대응표와 원고 개정.

최종 인계물은 `실험 계획/실제 시도 기록`, `원본-설정-그림 출처 manifest`, `재현 가능한 비교 결과`, `조건별 성공/실패와 사례`, `리뷰 항목별 원고 반영 위치`다. D/O/E 각각의 완료 여부와 실패·미측정 항목을 표시한다. “추가 실험 없이 충분하다”거나 “모든 리뷰가 해결된다”는 결론은 현재 근거로 내리지 않는다.
