## ⚙️ 2. 실험 기본 세팅 및 아키텍처

- **주행 방식**: 사전 매핑(Visual SLAM) 배제 ➔ **바퀴 오도메트리 + V-LiDAR 코스트맵 기반 순수 상대 주행**
- **목표 거리**: 출발점 기준 **전방 10.0m 직진 주행 (`rel_x = 10.0m`)**
- **명령 방식**: RViz 마우스 클릭 배제 ➔ 자동화 스크립트 실행:
  ```bash
  python3 scripts/test_avoidance_goal.py -d 10.0
  ```
- **개선된 핵심 파라미터**:
  - `robot_radius: 0.40m`, `inflation_radius: 0.60m` (현실적 안전 완충 폭 확보)
  - `BaseObstacle.scale: 1.5` (장애물 반발력 75배 강화)
  - `PathDist.scale: 16.0` (급격한 복귀로 인한 측면 충돌 방지)
  - `inf_is_valid: False` (차체 회전 시 시야 밖 장애물 삭제 방지)

## 🏢 3. 3가지 복도 환경 설계 (Environment Matrix)

논문에서 지적된 바닥 반사 및 공간 제약 조건을 철저히 검증하기 위해 특성이 다른 3곳을 선정합니다:

```
[복도 A: 표준 환경] ──────► [복도 B: 고반사 유광 바닥] ──────► [복도 C: 좁은 통로]
  (무광 타일, 균일 조명)       (바닥 조명 반사 극심 구간)        (양측 벽면 폭 협소)
```

| 구분 | 환경 명칭 | 주요 특징 및 실험 의의 | 권장 장소 예시 |
| :---: | :--- | :--- | :--- |
| **복도 A** | **표준 무광 복도**<br>*(Standard)* | • 조명 균일, 바닥 반사광 적음<br>• 복도 폭 2.2m 이상으로 충분한 우회 공간 제공<br>• 기본 V-LiDAR 및 Nav2 회피 기준선(Baseline) 확립 | 뉴턴홀 일반 복도 구간 |
| **복도 B** | **고반사 유광 복도**<br>*(High-Gloss / Reflection)* | • 왁스 칠된 대리석/유광 타일로 천장 형광등 반사 심함<br>• **논문의 주 실패 원인(11회 중 8회)**이었던 바닥 분할 노이즈 극복 여부 집중 검증 | 오석관 로비/복도 또는 중앙 통로 |
| **복도 C** | **좁은 제한 복도**<br>*(Narrow / Constrained)* | • 복도 폭이 1.6m ~ 1.8m 내외로 좁음<br>• 장애물 우회 시 벽면과 장애물 사이 틈새(Narrow gap) 통과 능력 검증 | 건물 측면 복도 또는 연구실 사이 복도 |

## 📦 4. 3가지 장애물 배치 시나리오 (Obstacle Scenarios)

10m 주행 구간 동안 로봇의 인지 및 회피 기동을 다각도로 평가합니다:

### 시나리오 1: 단일 중앙 정적 장애물 (Center Static)
- **배치**: 출발선 전방 **4.0m 지점 정중앙**에 규격 박스(가로 40cm × 세로 40cm × 높이 50cm) 1개 배치.
- **검증**: 기존 논문 시험의 직접 비교군. 정면 인지 후 우회 및 10m 도달 성공 여부.

### 시나리오 2: 경로 편향 오프셋 장애물 (Offset Obstacle)
- **배치**: 전방 **4.0m 지점, 중심선 기준 좌측 또는 우측으로 25cm 치우치게** 배치.
- **검증**: 로봇 전방 시야 한쪽에 걸치는 부분 장애물 인지 및 반대편 넓은 공간으로의 지능적 우회 검증.

### 시나리오 3: 연속 다중 장애물 (Sequential Double Obstacles)
- **배치**: 
  - 1차 장애물: 전방 **3.5m 지점 좌측**
  - 2차 장애물: 전방 **7.0m 지점 우측** (지그재그 슬라롬 코스)
- **검증**: 1차 회피 완료 후 즉시 2차 장애물을 연속 감지하여 연속 S자 회피 기동 수행 능력 검증.

## 📊 5. 통계적 유의성 확보를 위한 시행 횟수 (총 90회)

리뷰어의 *"validation is limited"* 지적을 완벽히 반박하기 위해 **환경당 30회, 총 90회**의 대규모 통계 데이터를 확보합니다:

$$\text{총 실험 횟수} = 3\text{개 복도} \times 3\text{개 시나리오} \times 10\text{회 반복} = \mathbf{90\text{회}}$$

### 📋 실험 매트릭스 구성표

| 환경 | 시나리오 1 (중앙 1개) | 시나리오 2 (편향 1개) | 시나리오 3 (연속 2개) | 환경별 소계 |
| :---: | :---: | :---: | :---: | :---: |
| **복도 A (표준 무광)** | 10회 | 10회 | 10회 | **30회** |
| **복도 B (고반사 유광)** | 10회 | 10회 | 10회 | **30회** |
| **복도 C (좁은 통로)** | 10회 | 10회 | 10회 | **30회** |
| **합계** | **30회** | **30회** | **30회** | **총 90회** |

## 📏 6. 평가 지표 및 성공/실패 판정 기준

### 1) 정량적 평가 지표 (Metrics)
1. **회피 성공률 (Success Rate, %)**: 
   $$\text{Success Rate} = \frac{\text{성공 횟수}}{\text{총 시행 횟수}} \times 100\%$$
   *(목표치: 기존 78% 대비 ➔ **90% 이상** 달성)*
2. **최소 안전 여유 거리 (Min Clearance, cm)**:
   - 주행 중 로봇 외곽과 장애물 사이의 가장 가까웠던 거리
3. **10m 완주 주행 시간 (Time to Goal, sec)**:
   - 장애물 회피로 인한 궤적 지연 시간 측정

### 2) 판정 기준
- ✅ **성공 (SUCCESS)**:
  - 장애물 및 벽면과 일체 접촉 없이 10m 목표 지점에 도달하여 `Navigation Succeeded!`가 뜸.
- ❌ **실패 (FAILURE)**:
  - **F1 (충돌)**: 장애물 모서리를 스치거나 접촉함.
  - **F2 (끼임/타임아웃)**: 코스트맵 왜곡으로 인해 회피 경로를 찾지 못하고 60초 이상 정지/회전 반복.
  - **F3 (벽면 이탈)**: 장애물을 과도하게 피하려다 복도 벽면에 충돌.

## 🚀 7. 실제 실험 단계별 실행 가이드

### [사전 준비] 최신 파라미터 빌드 (최초 1회 필수)
```bash
cd ~/ros2_ws
colcon build --symlink-install --packages-select omo_r1_navigation2 fake_lidar_with_tf freespace_detection
source install/setup.bash
```

---

### [매 회차 실행 순서]

#### Step 1. 로봇 출발선 배치 및 장애물 설치
- 로봇을 시작 지점에 놓고 바퀴 정렬.
- 시나리오에 맞게 거리 측정 테이프로 4m / 7m 지점에 박스 배치.

#### Step 2. 로봇 시스템 기동 (터미널 1)
```bash
cd ~/ros2_ws
source install/setup.bash
ros2 launch robot_launch_package multi_node_launch.py
```

#### Step 3. 센서 데이터 자동 녹화 시작 (터미널 2)
```bash
cd ~/ros2_ws
# 형식: ./scripts/record_rosbag.sh minimal <환경>_<시나리오>_run<번호>
./scripts/record_rosbag.sh minimal corridorA_scen1_run01
```

#### Step 4. 10m 전방 회피 주행 명령 전송 (터미널 3)
```bash
cd ~/ros2_ws
source install/setup.bash
python3 scripts/test_avoidance_goal.py -d 10.0
```

#### Step 5. 회차 종료 및 정리
1. 로봇이 10m 지점에 도착하면 터미널 2(`record_rosbag.sh`)에서 `Ctrl + C`로 녹화 종료.
2. 판정 결과(성공/실패 유형)를 기록지에 체크.
3. 다음 회차 준비를 위해 프로세스 리셋:
   ```bash
   ./stop_all.sh
   ```
4. 로봇을 다시 출발점으로 이동 후 반복 진행.
